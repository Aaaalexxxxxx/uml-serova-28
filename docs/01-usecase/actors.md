| Актёр | Кто это | Первичный? | Зачем приходит в систему |
|---|---|---|---|
| Клиент | пассажир, который заказывает поездку | да | заказать поездку, узнать цену, отменить заказ, оценить водителя |
| Водитель | исполнитель заказа, владелец автомобиля | да | получать заказы, принимать их, отмечать статус поездки, оценивать клиента |
| Диспетчер | сотрудник службы такси | да | контролировать активные заказы, разрешать спорные ситуации, блокировать пользователей |
| Платёжный шлюз | внешняя система (банк, эквайринг) | нет | проводит оплату поездки, возвращает статус транзакции |
| Картографический сервис | внешний API (Яндекс.Карты, 2ГИС) | нет | предоставляет геоданные для расчёта маршрута и расстояния |
